# AI Lab 1: Introduction to Artificial Intelligence

## Overview
This project explores the history of Artificial Intelligence, rule-based systems, probability-based decision-making, and the limitations of conversational tests.

## Project Files
- `AI LAB1 report.docx` — Lab report containing the tasks, results, analysis, reflection, and references.
- `lab1/lab1_rules.py` — Rule-based scholarship screening program with four test cases.
- `lab1/lab1_compare.py` — Comparison of symbolic rules and probability thresholds.
- `outputs.txt` — Program outputs.

## Requirements
Python 3. No external packages are required.

## How to Run
Run these commands from the `lab1` folder:

```bash
python lab1_rules.py
python lab1_compare.py
```

## Note
The probability values are synthetic examples. They are not predictions from a trained AI model, and the comparison does not measure model accuracy.
